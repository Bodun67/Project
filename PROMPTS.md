# Prompts для AI Agent

## Запит 1 — початкова версія
Створи адаптивний односторінковий сайт кав'ярні «Осіння Кава» на HTML, CSS і JavaScript. Використай коричнево-теракотову палітру, осінній настрій, м'які округлі картки й чотири секції: головний екран, історія, меню з цінами та контакти. Додай семантичну розмітку, мобільну версію і локальний запуск через `npm run dev`.

## Запит 2 — нова функція
Додай інтерактивного чорно-білого котика у стилі дружнього бонусного персонажа. Відвідувач може натиснути на нього один раз на день і отримати бонус -10% на каву. Збережи дату отримання бонусу в localStorage, покажи прогрес і повідомлення про наступне доступне погладжування. Також додай окремий блок про зерно з посиланням на сайт постачальника.

## Запит 3 — дизайн і checkpoint
Зроби фон головного екрана схожим на кав'ярню в осінньому провулку: фасади будинків, тепле світло, вивіска, мокра вулиця та листя, що падає. Зроби кути м'якими, перевір адаптивність і поверни попередній стан через Git, якщо новий дизайн погіршить читабельність.

## Checkpoint-и Git
- `initial cafe page` — початкова структура і базовий дизайн.
- `add daily cat bonus` — інтерактивний котик, localStorage та блок зерна.
- `autumn alley visual refresh` — фінальний осінній візуальний стиль.
